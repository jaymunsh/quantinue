## 4. 검증 시 함정 (이번에 실제로 밟은 것)

- **PDF 렌더만 믿지 말 것** — PDF는 넘친 내용을 페이지에 구겨 넣지만,
  브라우저 무대(1600×900)는 그대로 자른다. 9화면 각주가 그렇게 잘렸었다.
  **반드시 브라우저에서 확인**
- `.body`/`.ledger`가 둘 다 `margin-top:auto` — 내용이 조금만 넘쳐도
  **각주가 무대 밖으로 밀려 사라진다.** 장을 고치면 각주 생존부터 확인
- `data-notes` 안 생따옴표 금지(`&quot;`로) · 키 판정은 `e.code` ·
  장을 넣고 빼면 eyebrow 번호·대본·문서 번호를 같이 갱신 (`NEXT.md` 함정 모음)
- 규제 발언은 **"켜기 전 검토 목록으로 관리한다"까지만** — 법률 자문을
  받았다고 단정하지 않는다 (16화면 대본 ⚠️)
