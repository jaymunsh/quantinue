# 덱 모드 설명 — 헷갈릴 때 이것만

`slides/index.html`을 브라우저로 열면 시작됩니다. 모드는 사실상 셋뿐입니다.

## 모드 3가지

| 모드 | 여는 법 | 무엇이 뜨나 | 언제 쓰나 |
|---|---|---|---|
| **기본 보기** | 그냥 열면 이 상태 | 슬라이드만 | 혼자 훑어볼 때 |
| **전체화면** | `F` (한 번 더 누르면 해제) | 슬라이드만, 브라우저 UI 없이 | **프로젝터에 내보내는 화면** |
| **발표자 창 (대본 모드)** | `P` — 새 창이 하나 뜬다 | 현재 장 번호 · **대본(노트)** · 다음 장 제목 · 경과 시간 | **발표 때 노트북에서 보는 화면** |

### 발표 당일은 이 순서입니다

1. `index.html`을 연다
2. `P` → 발표자 창이 뜬다 → 이 창을 **노트북 화면**에 둔다
3. 원래 덱 창을 **프로젝터 화면**으로 옮기고 `F`(전체화면)
4. 어느 창에서 `→`를 눌러도 **두 창이 같이 넘어간다**

발표자 창의 시계는 `P`를 처음 연 순간부터 돌고, **12:30을 넘으면 붉어집니다.**
"타이머 0" 버튼으로 언제든 0부터 다시 잴 수 있습니다.

## ⚠️ `N`은 발표용이 아닙니다

`N`은 **같은 창 아래쪽에** 노트를 그립니다. 즉 프로젝터에도 그대로 나갑니다.
혼자 리허설할 때만 쓰고, 발표에서는 반드시 `P`(발표자 창)를 쓰세요.

## 이동 키 전부

| 키 | 하는 일 |
|---|---|
| `→` `Space` `PageDown` | 다음 장 |
| `←` `PageUp` | 이전 장 |
| `Home` / `End` | 첫 장 / **마지막 백업 장** |
| 화면 클릭 | 오른쪽 2/3 = 다음, 왼쪽 1/3 = 이전 |

- **백업 2장**은 본편 뒤에 있습니다. 진행 막대에 안 잡히고, 페이지 표시가
  "백업 1 / 2"로 바뀝니다. Q&A에서 질문 나올 때만 `→` 또는 `End`로 넘어갑니다.
- **영상(7화면)** 위에서는 스페이스·클릭이 슬라이드를 넘기지 않습니다
  (재생/일시정지가 먼저). 넘길 때는 `→`를 쓰세요. 장을 떠나면 자동으로 멈춥니다.

## 자잘한 것

- 한/영 상태와 무관하게 키가 먹습니다 (물리 키 기준 판정)
- `P` 창이 안 뜨면 팝업 차단입니다 — 주소창 오른쪽에서 허용 후 다시 `P`
- PDF(`quantinue-final.pdf`)는 인쇄용 스냅샷일 뿐, 발표는 HTML로 합니다
