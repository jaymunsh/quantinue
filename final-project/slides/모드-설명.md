# 덱 사용법 — 이게 전부입니다

`slides/index.html`을 브라우저로 열고, **`F`로 전체화면**. 모드는 그것뿐입니다.
(발표자 창·노트 기능은 07-28에 뺐습니다 — **대본은 [`대본.md`](대본.md)**,
인쇄해 가거나 폰으로 보면 됩니다.)

## 발표 당일

1. `index.html` 열기 → 프로젝터 화면으로 창 이동 → `F` (전체화면, 여백 없음)
2. 대본은 `대본.md`를 따로 준비 (종이 추천)

## 키

| 키 | 하는 일 |
|---|---|
| `F` | 전체화면 켜고 끄기 |
| `→` `Space` `PageDown` | 다음 장 |
| `←` `PageUp` | 이전 장 |
| `Home` / `End` | 첫 장 / **마지막 백업 장** |
| 화면 클릭 | 오른쪽 2/3 = 다음, 왼쪽 1/3 = 이전 |

- **백업 2장**은 본편 16장 뒤에 있습니다. 진행 표시에 안 잡히고 "백업 1 / 2"로
  표기됩니다. Q&A에서 질문 나올 때만 `→` 또는 `End`로 넘어갑니다.
- **영상(9화면)** 위에서는 스페이스·클릭이 재생/일시정지입니다. 장을 넘길 때는
  `→`. 장을 떠나면 자동으로 멈춥니다.
- 한/영 상태와 무관하게 키가 먹습니다 (물리 키 기준 판정).
