> ## AI를 쓸 곳과 안 쓸 곳을 구분했다
>
> **[비율 막대]** 기계 규칙 **84%** ┃ AI 비평가 **16%** ✅
>
> ### ① 안 쓸 곳을 먼저 정했다
> 손절·익절은 AI에게 묻지 않는다. 1분마다 기계적으로 지킨다.
> → 아무 일 없는 1분에는 **AI 호출 0회**
>
> ### ② 쓴 곳은 비용을 통제한다
> 하루 상한 · 위급한 매도용 20% 별도 예약 · 같은 종목 30분 재호출 금지
> → 실측 4일 **$0.53** (상한 $3/일의 7% 미만) ✅
>
> ### ③ 검증을 2단으로 나눴다
> 기계 규칙이 먼저 걸러 **84%는 AI까지 가지도 않는다**
> 애매한 나머지만 AI 비평가가 반박 → **전체 판단의 18%를 반려** ✅
>
> ### ④ 판단을 재현할 수 있게 남겼다
> **근거는 처음부터 342건 전부.**
> 07-21에 재현성 기록을 넣은 뒤로는 **234건 전부**에
> 모델 · 프롬프트 버전 · 입력 지문까지 남는다 ✅

**[원장]** `tb_llm_usage` 4일 합계 $0.53 / 상한 $3·일 ·
`tb_critic_verdict` 게이트 271(84%) / LLM 52(16%) · 반려 57 / 323 = 17.6%

⚠️ **④는 "모든 판단"이라고 말하지 않는다.** 원장 실측은
`prompt_version` 234 / 342이다. 07-20 이전 102건은 재현성 기록을 넣기 전
구간이고, 그 구간에는 로컬 Qwen과 mock 판단이 섞여 있다. 숨기지 말고
**"넣은 시점부터는 100%"**로 말한다 — 이게 오히려 성장 서사가 된다.
`policy_version`은 342건 전부 비어 있으므로 **말하지 않는다.**

⚠️ **"100%"에 반례가 있냐고 물으면** — 07-21 이후 판단은 240건인데
`prompt_version`은 234건이다. **차이 6건은 누락이 아니다.** 그 6건은
`model_provider`조차 비어 있는 **규칙 기반 자동 청산(손절·익절 매도)**이라
애초에 프롬프트가 없다. 정확한 문장은 **"LLM이 판단한 234건은 누락 0건"**이고,
이건 오히려 ①번("손절은 판단이 아니라 규칙이다")의 원장 증거다 —
**공격받는 자리가 아니라 되받아치는 자리다.** (2026-07-27 실측:
`WHERE cycle_ts::date >= '2026-07-21'` → LLM 234 · 누락 0 · 규칙 6)

**[말]**

## 백업 슬라이드 (질문 대비) — 덱 백업 1·2

한 장에 다 넣으니 넘쳐서 **범위·설계**(12화면)와 **숫자·검증**(13화면)으로 갈랐다.

| 질문 | 답변 요지 |
|---|---|
| 실거래는 왜 안 하나요? | 브로커 주문만 뺐고 나머지는 전부 실물. 검증 후 켜는 마지막 스위치 |
| 배포는 왜 안 했나요? | **판단이 뒤집힌 항목이다.** 처음엔 필요 없다였으나 운용자 이동으로 재판정 → "이전이 정당하다", 착수만 보류. 한다면 EC2 t4g.small급·SSM·SSH 터널·`pg_dump` 이관 ✅ |
| AI가 시장을 이기나요? | 수익률 주장이 아니라 파이프라인·비용 통제가 가치. `/me`에 SPY 비교 화면 ⚠️ 데모에서는 비어 있으니 **운영 8020으로 띄운다** |
| 환각은 어떻게 막나요? | 근거 묶음 제공 → 비평가 반려(18%) → 판단 기록으로 사후 추적. "막는다"가 아니라 **"거르고 추적한다"** |
| 프롬프트 관리는? | 프롬프트 버전을 판단 원장에 함께 기록(07-21 이후 234건). 성향별 분리 |
| 재현 기록이 234건뿐인가요? | 07-21 이후 판단 **240 = LLM 234(누락 0) + 규칙 6**. 그 6건은 손절·익절 자동 청산이라 프롬프트가 없다 — "손절은 AI에게 안 묻는다"의 원장 증거 ✅ |
| 테스트는 다 통과하나요? | **유닛·웹 803 · 통합 190 전부 통과**(2026-07-28 02:20 실측). 통합은 일회용 PostgreSQL을 띄워 돌린다 ✅ |
| 계보를 전부 남기나요? | 모델·프롬프트 버전·입력 지문은 남긴다. **`policy_version`은 컬럼만 잡아두고 배선은 안 했다** — 342건 전부 비어 있다 ⚠️ |
| 공시·뉴스는 판단에 쓰이나요? | 수집·정규화까지는 돈다(뉴스 10,728·공시 8,973). 다만 **채점을 판단에 물리는 구간은 아직 얕다** — 계보 기준 6/342·0/342. **모은 것과 판단에 쓴 것은 다르다** ⚠️ |
| 영상은 각본 아닌가요? | 맞습니다. 그래서 마지막 20초에 실제 운영 기록을 붙였습니다 |
| 본인은 뭘 했나요? | 1차 Reviewer·메모리 설계·구현, 2차는 전체를 인수받아 장중 감시·사건 재판단·운영 마무리 |
| 계좌가 왜 여러 개? | 운용 6 + 회귀 검증용 4 = **등록 10**. 관제실이 **9**로 세는 건 1개가 일시정지라 활성만 세기 때문 ✅ |
| 계좌 이름이 왜 `DEMO-`인가요? | 브로커 **모의 계좌**라는 뜻. 실제 운영인지는 화면 좌하단이 말한다 — 운영 `LLM openai`, 데모 `LLM mock` ✅ |
| AI 비용이 얼마나? | 실측 4일 $0.53, 하루 상한 $3. 요율 미선언 모델은 기동 자체를 거부 |
| T+5 회고는요? | 1차에서 설계·구현한 파트. 2차 원장에는 아직 데이터가 없다(`tb_review` 0건) — **실적 주장 금지** ⚠️ |
